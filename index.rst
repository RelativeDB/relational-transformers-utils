Relational Transformers Utils
=============================

Utility tooling that wires `Relational Transformers
<https://relationaltransformers.com>`_ into a product: context collection,
normalization, ablation measurement, metrics, checkpoint quantization, and
RelBench benchmark utilities. Applications own retrieval and encoding; the
core package owns the model; this package covers the numeric steps between.
